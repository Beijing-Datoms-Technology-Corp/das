# 数据编织器使用指南

## 概述

**数据编织器** 是 DAS 的核心功能，提供直观的拖拽式界面来建立和管理数据资产之间的关系。通过可视化的方式，你可以：

- 🔗 建立数据文件间的引用关系
- 📊 创建数据血缘图
- 🎯 定义数据转换流程
- 📋 实施合规性规则

## 界面介绍

### 主要区域

1. **文件面板** (左侧)
   - 显示工作区中的所有数据文件
   - 支持文件类型过滤
   - 显示文件大小和修改时间

2. **画布区域** (中央)
   - 拖拽文件创建节点
   - 鼠标滚轮缩放
   - Alt+拖拽平移视图

3. **属性面板** (右侧，计划中)
   - 显示选中节点的详细信息
   - 编辑节点属性和关系

### 工具栏功能

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| 💾 Save | 保存编织图 | - |
| 🔄 Refresh | 刷新文件列表 | - |
| 🗑️ Clear | 清空画布 | - |
| 📐 Fit | 适应屏幕 | - |

## 基本操作

### 1. 启动编织器

```bash
Ctrl+Shift+P → "DAS: Open Weaver"
```

### 2. 添加数据节点

1. 在左侧文件面板中找到目标文件
2. 拖拽文件到中央画布
3. 松开鼠标创建节点

支持的文件类型：
- 📄 **PDF 文档** - 红色边框
- 🗄️ **数据库文件** (CSV, Parquet) - 蓝色边框
- 📄 **其他文档** - 灰色边框

### 3. 创建关系连接

1. 将鼠标悬停在节点边缘
2. 点击并拖拽连接点
3. 拖拽到目标节点释放

支持的关系类型：
- **引用关系**: 数据A引用数据B
- **依赖关系**: 数据A依赖数据B
- **转换关系**: 数据A转换为数据B

### 4. 节点操作

#### 双击节点
- 打开对应的数据预览器
- 查看文件详细内容

#### 右键菜单 (计划中)
- 重命名节点
- 删除节点
- 查看属性
- 设置关系类型

## 高级功能

### 缩放和平移

- **缩放**: 鼠标滚轮
- **平移**: Alt + 鼠标拖拽
- **适应屏幕**: 点击 "📐 Fit" 按钮

### 节点布局

- 自动布局算法避免重叠
- 手动拖拽调整位置
- 智能连接线避开节点

### 数据验证

编织器会自动验证：
- 文件存在性
- 关系一致性
- 循环依赖检测

## 保存和加载

### 自动保存
- 每次操作后自动保存到 `das-graph.json`
- 支持撤销/重做 (计划中)

### 导出功能 (计划中)
- 导出为图片 (PNG/SVG)
- 导出为文档 (PDF)
- 导出为数据格式 (JSON/XML)

## 最佳实践

### 1. 组织结构

```
建议的节点布局：
├── 数据源 (顶部)
├── 处理节点 (中间)
└── 输出结果 (底部)
```

### 2. 命名规范

- 使用描述性名称

- 添加版本号或日期

### 3. 关系管理

- 保持关系清晰简洁
- 避免过度复杂的连接
- 定期清理无效关系

### 4. 版本控制

- 定期保存重要版本
- 在提交前验证关系完整性
- 为复杂项目创建分支

## 故障排除

### 无法拖拽文件

**原因**: 文件面板未正确加载
**解决**: 点击 "🔄 Refresh" 重新加载

### 连接线不显示

**原因**: 节点位置重叠
**解决**: 手动调整节点位置或使用 "📐 Fit"

### 保存失败

**原因**: 工作区权限问题
**解决**: 检查文件夹写权限

### 性能问题

**原因**: 节点数量过多
**解决**:
- 分批处理大型项目
- 使用筛选器隐藏不相关节点
- 定期清理临时节点
